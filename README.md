# TILT CHECK

핸드폰 긴 옆면을 부재에 대고 **지주캡 각도**를 재는 웹앱(PWA)입니다.
블록 설계값(T.A TRANSVERSE ANGLE · F.A FRAME ANGLE)과 캡 취부각도(δ · 방향)로 정상값을 계산하고,
실측값으로 **캡이 실제로 몇 도 돌아갔는지(회전오차)** 를 바로 보여줍니다.
FRAME · LONGL. · 임의 방향 라인을 재는 **일반 부재 측정**은 추가 기능입니다.

- 설치 없이 브라우저에서 열고, 홈 화면에 추가하면 앱처럼 씁니다.
- 한 번 열고 나면 **비행기 모드에서도** 실행 · 측정 · 기록이 됩니다.
- 모든 데이터는 **그 폰 안에만** 저장됩니다 (서버 없음, 외부 전송 없음).
- **폰 센서 값은 참고용입니다. 판정은 반드시 디지털 수평계로 합니다.** (앱도 측정할 때 이 경고를 띄움)

## 접속 · 홈 화면에 추가

접속 주소 : **https://chjino-prog.github.io/Tilt-Check/**

| 폰 | 방법 |
|---|---|
| 안드로이드 (크롬) | 주소 열기 → 오른쪽 위 ⋮ → **홈 화면에 추가** (또는 '앱 설치') |
| 아이폰 (사파리) | 주소 열기 → 아래 공유 버튼 □↑ → **홈 화면에 추가** |

아이폰은 처음 측정할 때 **센서 켜기** 버튼을 눌러 '동작 및 방향' 접근을 허용해야 합니다.

## 처음 쓸 때

1. **설정 → 영점 보정** : 평평한 곳에 폰을 대고 한 번, 180° 돌려 같은 자리에서 한 번. (폰마다 한 번)
2. **설정 → 합격 허용오차** (기본 ±3.0°) : 지주캡 A · B 편차가 이 안이면 OK, 넘으면 NG. 역산 회전각이 넘으면 '주의'.
3. 측정 탭에서 **블록 추가** → **지주캡 추가** → 캡을 눌러 **측정 시작**.

자세한 사용법은 [docs/사용설명서.md](docs/사용설명서.md).

## 개발

```powershell
npm install
npm run dev        # 개발 서버 (같은 와이파이의 폰에서는 https 가 아니라 센서가 안 될 수 있음)
npm test           # 계산 모듈 단위시험
npm run build      # dist/ 에 배포 파일
```

배포는 `main` 브랜치에 올리면 GitHub Actions 가 자동으로 합니다 → [docs/배포.md](docs/배포.md).
