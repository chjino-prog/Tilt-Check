# 배포 (GitHub Pages)

센서 API 는 **https** 에서만 동작하므로 GitHub Pages 공개 저장소에 정적 파일로 올립니다.
저장소에는 호선번호 · 블록값 같은 회사 데이터를 넣지 않습니다.
(`작업지시서_*.md` 와 원본 그림은 `.gitignore` 로 빠져 있음. 예시값은 `src/calc/angle.test.ts` 에만 있음)

## 처음 한 번 — 저장소 만들기

1. https://github.com 에 로그인 → 오른쪽 위 **＋** → **New repository**
2. **Repository name** : `tilt-check` (원하는 이름 가능 — 접속 주소에 들어감)
3. **Public** 선택. 아래 'Add a README' 등은 **아무것도 체크하지 않음** → **Create repository**
4. 만들어진 화면에 보이는 주소 `https://github.com/<아이디>/tilt-check.git` 를 복사
5. 이 폴더에서 올리기 (처음엔 GitHub 로그인 창이 뜸)

```powershell
git remote add origin https://github.com/<아이디>/tilt-check.git
```

```powershell
git push -u origin main
```

6. 저장소 **Settings → Pages** → **Build and deployment / Source** 를 **GitHub Actions** 로 바꿈
7. **Actions** 탭에서 '배포' 가 초록 체크가 되면 완료 → `https://<아이디>.github.io/tilt-check/`
   - 6번을 올린 뒤에 했다면 Actions 탭에서 '배포' → **Run workflow** 로 한 번 더 돌립니다.

## 그 다음부터

고친 내용을 커밋해서 `git push` 하면 자동으로 단위시험 → 빌드 → 배포됩니다.
폰에서는 앱을 껐다 켜면(또는 두 번째 실행 때) 새 버전으로 바뀝니다.
