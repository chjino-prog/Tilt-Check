# 지주캡 계산식 (1.7.0)

계산식은 작업지시서 2 · 3장 식 그대로이고, 1.6.0 부터 **식에 넣는 값**을 바르게 바꾼다 (2026-11-24 현장 분석).
1.7.0 : 외판 기울기 보정을 정확식으로 바꾸고, 판정을 **A · B 현물 비교**로 바꿨다 (역산 회전각은 참고 — 10장).
코드 : `src/calc/angle.ts` (식) · `sign.ts` (부호 · 턴오버 · 외판 보정) · `basis.ts` (T.A 경사) · `capcalc.ts` (기록 칸).
이 문서의 예시값은 지어낸 값이다 (회사 데이터 아님).

## 1. 넣는 값
| 기호 | 뜻 | 어디서 |
|---|---|---|
| T.A | FRAME 방향 수평선의 경사 | 현물 : 폰으로 잰 값 그대로 / 도면 : 2-1 로 바꿈 |
| F.A | FRAME 면이 연직에서 누운 각 (= LONGL. 라인 경사) | 도면 · 현물 |
| F.A 방향 f | FRAME 이 누운 쪽 = LONGL. 낮은 끝. 선수 +1 · 선미 −1 | 도면 · 현물 |
| δ | 캡취부각도 = **외판 면 위**에서 FR 선과 캡 중심선 사이 각 | 도면 |
| 캡 방향 c | 캡 WEB 의 **외판 쪽 끝**이 간 쪽. 선수 +1 · 선미 −1 (δ 0 이면 +1) | 도면 |
| θ | 캡 자리 외판 기울기 = 캡이 있는 FR 단면에서 외판 접선과 A/B 수평선 사이 각 (0 ~ 90°) | 도면 (δ 0 캡은 필요 없음) |
| 자세 | 잴 때 지주캡이 보는 쪽 : 바닥(보통) / 하늘(턴오버 후) | 현장 |
| A | 각도 A 실측 (WEB 방향) — 크기만 | 현장 |
| B | 각도 B 실측 (WEB 직각) — 크기 + 높은 쪽(선수 / 선미) | 현장 |

## 2. 식에 넣기 전에 바꾸기
**2-1 도면 T.A → 경사** (도면 기준일 때만. 도면 T.A 는 단면도에서 본 회전각이고, FRAME 면이 F.A 만큼 누우면 같은 선이 덜 가팔라진다)

    TA = asin( sin T.A도면 · cos F.A )

**2-2 회전 부호** (도면 '돌아간 방향' 은 외판 쪽 끝 기준. 캡이 바닥을 보면 그 끝이 낮은 끝, 하늘을 보면 높은 끝이라 뒤집는다)

    s = c × f × (하늘이면 −1, 바닥이면 +1)

**2-3 캡 상판 δ** (캡 WEB 은 세로판이라 외판이 서 있을수록 외판 위에서는 덜 돌아간 것처럼 보인다. δ 0 이거나 θ 가 없으면 δc = δ)

    tan δ외판 = tan δc · cos θ   (WEB 연직 — 정확식, 1.7.0)
    δc = atan( tan δ / cos θ )                    θ < 90° 이면 모든 δ 에서 계산 (θ = 90° 만 불가)
    작은 δ 는 대략 δc ≈ δ ÷ cos θ  (θ 45° → 1.41배, 60° → 2배, 75° → 3.89배)

1.6.0 근사식 `atan( tan δ / √(cos²θ − tan²δ · sin²θ) )` 은 δ 가 커지면 틀어지고 δ ≥ 90° − θ 에서 계산이 안 됐다.
δ 3° · θ 73° → 10.16° (1.6.0 은 10.31°), δ 10° · θ 73° → 31.09° (36.44°), δ 17° · θ 73° → 46.28° (계산 불가).

외판 **길이방향(선수미 방향) 기울기는 계산에서 뺀다** — 20° 까지 영향 0.2° 이하, 30° 에서 약 0.5° 라 현장 판정에 지장 없음.

## 3. 정상값 (작업지시서 식, δ 자리에 δc)

    θA = asin( sin TA · cos δc + s · sin F.A · sin δc )
    θB = asin( sin F.A · cos δc − s · sin TA · sin δc )

θB > 0 이면 **F.A 반대쪽이 높음**, θB < 0 이면 F.A 쪽이 높음. 화면 · 기록은 크기 + 높은 쪽으로 쓴다.

## 4. 1° 당 변화

    dA상판 = | s · sin F.A · cos δc − sin TA · sin δc | / cos θA
    dB상판 = | sin F.A · sin δc + s · sin TA · cos δc | / cos θB
    도면 δ 1° 당 = 상판 값 × k
    k = dδc/dδ = (1 / cos θ) · (1 / cos²δ) ÷ (1 + tan²δc)     (δ 0 이거나 θ 없으면 1)

## 5. B 실측 → 실제 δ → 회전오차

    B부호 = +B (F.A 반대쪽이 높음) / −B (F.A 쪽이 높음) / 0 (수평)
    R  = √( sin²F.A + sin²TA )
    φ  = atan2( s · sin TA , sin F.A )             ← 엑셀은 ATAN2(sin F.A, s · sin TA) (x, y 순서)
    c  = acos( sin B부호 / R )                     ( |sin B부호 / R| > 1 이면 역산 불가 )
    δ1 = c − φ ,  δ2 = −c − φ                     ( −180 ~ 180 으로 )
    δc실제 = δ1 · δ2 중 δc 에 더 가까운 값
    δ실제 = atan( tan δc실제 · cos θ )                  (외판 위 각도. δ 0 이거나 θ 없으면 δc실제 그대로)
    회전오차 = δ실제 − δ      → 참고값 (판정에는 안 씀, 10장)

회전오차 + 는 캡 방향 쪽으로 '더' 돌아감, − 는 '덜' 돌아감. δ 0 캡은 + = 선수 쪽.
실제 δ · 회전오차는 도면과 같은 외판 위 각도라 도면 δ 와 바로 비교한다.

## 6. A 예측 · 잔차

    A예측 = θA( TA, F.A, δc실제, s )
    A잔차 = A실측 − A예측          ( A 부호는 정상 A 부호를 따른다 )

## 7. 방향 점검 (판정 보류)

    A지금 = θA( TA, F.A, δc, s ) ,  A반대 = θA( TA, F.A, δc, −s )
    |A지금 − A반대| ≥ 0.4° 이고  | A실측 − |A반대| | + 0.3 < | A실측 − |A지금| |  이면 보류

캡 방향 · F.A 방향 · 자세(바닥 / 하늘) 중 하나가 반대로 들어간 것으로 본다.

## 8. 엑셀 계산시트
앱과 같은 식을 엑셀 함수로 넣은 계산시트를 `tools/make_calc_sheet.py` 가 만든다 (저장 : 내 문서\TILT CHECK\TILTCHECK_지주캡_계산시트_<버전>.xlsx).

    python tools/make_calc_sheet.py [저장 경로]

- [계산] 시트 : 위쪽 흰 칸에 블록 값(기준 · T.A · F.A · FRAME 누운 쪽 · 자세 · 허용오차), 아래 캡 줄(40줄)에 캡 No · δ · 돌아간 방향 · 외판 θ · A · B · B 높은 쪽을 넣으면 정상값 · 편차 · 판정 · 주의 사유 · 참고값이 나온다. 계산 과정 칸은 접혀 있다 ([+] 로 펼침).
- [계산식] 시트 : 이 문서 2 ~ 7장과 10장을 칸 이름으로 풀어 쓴 설명.
- 블록 값은 이름 정의(`BASIS` · `TA_IN` · `FA_IN` · `FA_LEAN` · `POSE` · `TOL`, 계산값 `TA_C` · `FA_C` · `F_DIR` · `U_SIGN` · `SCALE`)로 식에서 부른다.
- 식을 고치면 앱과 시트를 같이 고치고, 지어낸 값 수백 건으로 앱 값 = 엑셀 값(1e-6° 안, 판정 · 주의 사유 글자까지)인지 대조한다 (1.7.1 : 384건 일치).

## 10. 판정 (1.7.0)
합격 · 불합격은 **A · B 실측과 정상값의 단순 비교**로 정한다. 허용오차 t 는 설정 '합격 허용오차' (기본 ±3.0°, 0.1° 단위).

    A편차 = A실측 − θA ,  B편차 = B부호 − θB
    NG   : |A편차| > t 또는 |B편차| > t
    주의 : A · B 는 t 안인데 |회전오차| > t 이거나 역산 불가
    OK   : 둘 다 아님
    θ 미입력 : δ 가 있는데 외판 기울기 θ 가 비어 있음 — 잰 값만 두고 판정 안 함 (θ 를 넣으면 같은 실측으로 판정)
    회전 환산 배율 = 1 / sin TA     (B 1° 오차가 회전 몇 ° 로 보이는지)

역산 회전각을 판정에 안 쓰는 이유 : 캡이 1° 돌 때 B 는 약 sin TA° 만 변해서, B 측정 오차가 회전각에는 1/sin TA 배로 커진다
(TA 46.7° → 1.4배, 34.4° → 1.8배, 17.4° → 3.3배). TA 24° 미만(배율 2.5 초과)에서 주의가 나오면 그 사실을 사유에 함께 적는다.
방향 점검(7장)에 걸리면 판정은 여전히 보류. 기록에는 그 측정 때의 허용오차 · 배율 · 주의 사유가 남는다.
