# TILT CHECK 사용설명서

## 화면 구성
| 탭 | 하는 일 |
|---|---|
| 측정 | 블록 목록(호선별) → 블록 → 지주캡 측정 / 다른 부재 재기 |
| 기록 | 블록별 측정 기록, CSV 내보내기 |
| 설정 | 판정 기준, 영점 보정, 표시 자릿수, 진동, 테마 |

## 먼저 알아둘 것
- 폰 중력센서는 기기 · 케이스에 따라 0.1 ~ 0.5° 오차가 납니다. **판정은 디지털 수평계를 우선으로** 하고, 폰 값은 참고로만 씁니다.
- 앱을 켜고 처음 측정 화면에 들어갈 때마다 이 경고가 한 번 뜨고, 측정 · 결과 화면 아래에도 표시됩니다.
- 디지털 수평계 값은 '직접 입력'으로 넣으면 같은 계산(역산 · 잔차 · 판정)을 합니다.

## 폰 대는 법
- 폰의 **긴 옆면**을 잴 라인에 댑니다. 눕혀 대든 세워 대든 같은 값이 나옵니다.
- 숫자 옆 ▲ = 폰 **윗단(카메라 쪽)이 높음**, ▼ = 윗단이 낮음.
- 케이스 · 카메라 돌출부 때문에 옆면이 뜨지 않게 대세요. 뜨면 케이스를 벗기고 영점 보정을 다시 합니다.
- 테두리가 **초록**이 되면(안정) 화면 아무 곳이나 눌러 값을 고정합니다. 다시 누르면 풀립니다.
- '움직임 감지' 가 뜨면 값 갱신을 멈춘 상태입니다. 폰을 멈추면 다시 잽니다.

## 부호(+/−)는 쓰지 않습니다 — 방향만 고릅니다
도면이 "F.A 선미로 3.2°", "캡 선미로 7°" 처럼 주는 그대로, 앱에도 **숫자 + 선수/선미** 로 넣습니다. 부호는 앱이 붙입니다.

| 넣는 곳 | 넣는 것 |
|---|---|
| 블록 | T.A 숫자, **F.A 숫자 + F.A 방향(선수/선미)** |
| 지주캡 | δ 숫자 + 돌아간 방향(선수/선미) |
| 각도 B (F/A 방향) | 숫자 + **높은 쪽(선수/선미)** |
| 각도 A (T/A 방향) | 숫자만 (어느 쪽으로 대도 됨) |

- 숫자 칸에 '-' 를 쳐도 지워집니다. 디지털 수평계 ▲▼ 는 **높은 쪽 고르기**로만 옮깁니다.
- **F.A 방향 쪽 끝이 낮습니다.** F.A 선미 블록이면 TS캡(δ=0) · DECK LONGL. 라인은 **선수 쪽이 높습니다** (2026-11-21 현장 확인).
- 계산 : F.A 와 캡이 같은 쪽(선미·선미, 선수·선수)이면 같은 식, 반대면 반대 식으로 계산합니다. F.A 선미 블록은 선수·선미를 통째로 뒤집어 본 F.A 선수 블록과 같기 때문입니다.
- 1.2.0 전에 만든 블록은 F.A 방향이 비어 있어 **선수로 계산**합니다. 캡 화면에 'F.A 방향을 아직 안 정했어요' 가 뜨면 눌러서 정합니다.

## 지주캡 측정
1. 블록 추가 : 호선, 블록, **T.A TRANSVERSE ANGLE**, **F.A FRAME ANGLE + F.A 방향(선수/선미)** (T.A · F.A 는 선택 — 모르면 비워 두고 아래 '현물 기준'으로 잽니다)
2. 지주캡 추가 : 캡 No, **δ**(도면 캡 취부각도), 돌아간 방향(선수 / 선미)
3. 캡을 누르면 **측정 순서 화면**이 나옵니다 — 정상값 카드(B · A, dA, dB)와 B · A 두 줄.
   - 정상 B 는 '0.74° · 선미 높음' 처럼 높은 쪽으로 보여 줍니다.
   - 카드 위에 어느 기준(도면 / 현물)의 T.A · F.A 로 계산했는지 표시됩니다.
   - δ 가 0 인 캡은 돌아간 방향(선수/선미)을 표시하지 않습니다.
   - dA 가 'A 민감도 하한'(기본 0.3)보다 작으면 A 는 회전 판정에 못 쓰고 참고로만 봅니다.
4. **측정** (측정 방향 그림 : 메뉴 › 측정 방향 그림)
   - **B (F/A 방향)** : 주판 위, 브라켓과 평행 (TS = ④ 주판 · ②③ 과 평행, PSA = ③ 주판 · ④⑤ 와 평행)
     - 폰 : '폰 머리(카메라 쪽)가 향한 쪽' 을 고르면 앱이 '선미 쪽이 높아요' 처럼 알려 줍니다. 고른 값은 기억합니다.
     - 디지털 수평계(직접 입력) : 숫자를 넣고 **어느 쪽이 높아요? 선수 / 선미** 를 고릅니다. 안 고르면 다음으로 못 갑니다.
   - **A (T/A 방향)** : 주판 위, WEB 과 평행 (TS = ① 과 평행, PSA = ①② 와 평행). 숫자만, 방향 상관없음.
   - **한 방향씩 저장** : '저장하고 A 재기' 를 누르면 B 값이 바로 저장됩니다. 뒤로 가거나 화면을 나갔다 와도 남아 있고, 순서 화면에서 그 줄만 눌러 다시 잴 수 있습니다. 하루 지난 값은 버립니다. 메뉴 › '잰 값 지우고 처음부터'로 지웁니다.
5. 결과
   - **회전오차** = 실제 δ − 도면 δ (B 값으로 역산) → 허용 회전오차 기준 OK / NG
   - **A 잔차** 가 기준(기본 0.5°)을 넘으면 'WEB 방향 숙어짐 / 측정 위치 의심' 경고 → 재측정
   - 평면도 : 빨간 점선 FRAME선, 회색 도면 WEB, 파란 실제 WEB
   - **높은 쪽을 반대로 고른 것 같으면** 경고가 뜹니다 (반대로 넣으면 회전오차가 확 줄어드는 경우, 특히 δ=0 캡). '선수 쪽이 높았어요' 를 누르면 다시 재지 않고 바로 고쳐집니다.
6. 메모 · 사진(선택)을 붙여 **기록 저장** (저장하면 잰 값은 지워짐)

## 현물 기준 (T.A · F.A 를 몰라도 될 때)
도면 T.A · F.A 대신, 지금 작업 중인 블록의 기준 부재를 **같은 폰으로** 재서 그 값으로 정상값을 계산합니다.
기준과 지주캡을 같은 폰으로 재므로 폰 센서의 치우침 · 블록 세팅 기울기가 양쪽에 같이 들어가 비교에서 대부분 지워집니다. 계산식은 그대로이고 들어가는 T.A · F.A 만 바뀝니다.

1. 블록 화면 → **현물에서 재기**
2. 1/2 **T.A** : **DECK 상면**, CAMBER 없는 구간의 **FRAME 라인**. 숫자만.
3. 2/2 **F.A** : **DECK 상면 LONGL. 라인**. 숫자 + **높은 쪽**. F.A 방향은 높은 쪽의 반대로 정해집니다.
   - 도면 F.A 방향과 반대로 나오면 'F.A 방향이 도면과 반대예요' 경고
   - **반드시 CENTER LINE 과 평행한 LONGL. 라인**을 잽니다. **경사 부재는 재면 안 됩니다.**
   - 변형에 취약한 **ANGLE 부재는 되도록 피하고, GIRDER 류 강력부재**에서 잽니다.
   - SHEER 없는 구간에서 잽니다.
4. 확인 화면 : 도면값이 있으면 차이를 보여줍니다.
   - 둘 다 일반 편차 1단계(기본 0.5°) 안이면 '블록 세팅이 도면과 거의 같아요'
   - 2단계(기본 1.0°)를 넘으면 경고 → CAMBER · SHEER 구간, 경사 부재, CENTER LINE 과 평행하지 않은 라인인지 확인
   - F.A 가 T.A 보다 크면 FRAME · LONGL. 라인을 바꿔 잰 건 아닌지 경고
5. **이 기준 쓰기** → 그 블록의 지주캡 · 다른 부재가 모두 현물값으로 계산됩니다.

- T.A · F.A 숫자는 크기만 씁니다. 두 값은 하나씩 저장되며, 한쪽만 재고 나가도 남습니다.
- 도면값 · 현물값이 둘 다 있으면 블록 화면에서 **계산 기준(도면값 / 현물값)** 을 바꿀 수 있습니다.
- 블록을 복제하면 현물값은 복사되지 않습니다 (블록마다 다시 잽니다).
- 측정 화면의 '어디에 대요?' 를 누르면 기준 부재 고르는 법이 나옵니다.

## 다른 부재 재기 (추가 기능)
블록 화면 → '다른 부재 각도 재기'
- **FRAME** (정상값 = T.A) / **LONGL.** (정상값 = F.A) — 현물 기준이면 '(현물)' 표시 / **임의각** (ψ, 선수/선미 입력, 블록 F.A 방향 반영)
- 편차 = |실측| − |정상|. 허용 1단계 이하 초록, 2단계 이하 주황, 넘으면 빨강.
- 기울기 그림의 차이는 눈에 보이도록 5배로 그립니다 (숫자는 실제 값).

## 센서가 없거나 막혔을 때
'직접 입력' 을 누르면 디지털 수평계 값을 숫자로 넣어 같은 계산을 합니다. 부호 대신 높은 쪽(선수/선미)을 고릅니다.

## 기록 · CSV
- 같은 블록에서 캡들의 (최근) 회전오차 부호가 모두 같으면 '마킹 기준 · 방향 · 세팅 확인' 경고가 뜹니다.
- 오른쪽 위 내보내기 버튼 → CSV (엑셀에서 바로 열림)
  - **다운로드 폴더에 저장** : 폰 '내 파일 › 다운로드' 에 저장. USB 로 회사 PC 에 옮길 때
  - **다른 앱으로 보내기** : 공유 시트 (파일 보내기를 지원하는 폰에서만 보임)
- CSV 열 순서 :
  일시, 호선, 블록, 모드, 캡No, 측정방향, T.A, F.A, δ(도면), 회전방향, 정상값A, 정상값B, 실측값A, 실측값B, 편차A, 편차B, δ_real, 회전오차, A잔차, 판정, 메모, 기준, F.A방향, 실측B높은쪽, 정상B높은쪽
  (일반 부재는 A 열에 정상값 · 실측값 · 편차. T.A · F.A 는 그때 계산에 쓴 값(크기), 기준 = 도면 / 현물)
  - 정상값B · 실측값B 의 부호 : + = F.A 반대쪽이 높음, − = F.A 쪽이 높음. 헷갈리면 뒤의 '높은쪽' 열을 봅니다.
- 데이터는 폰 브라우저 안에만 있으므로, 브라우저 데이터를 지우면 함께 지워집니다. 중요한 기록은 CSV 로 보관하세요.

## 설정
| 항목 | 기본 |
|---|---|
| 허용 회전오차 | 없음(기준미정) |
| A 잔차 경고 | 0.5° |
| A 민감도 하한 | 0.3 °/° |
| 일반 편차 1단계 / 2단계 | 0.5° / 1.0° |
| 표시 소수 자릿수 | 1자리 (결과 화면 · CSV 는 2자리) |
| ▲▼ 방향 반대로 | 끔 — 폰 윗단이 높은데 ▼ 가 보이는 기기에서 켭니다 |

## 바뀐 점
### 1.2.0 (2026-11-21)
- **부호 입력 없앰** : 블록 F.A 방향(선수/선미), 각도 B 는 숫자 + 높은 쪽, 각도 A 는 숫자만. 직접 입력의 ± 버튼 없앰
- **F.A 선미 블록 계산 바로잡음** : 캡 방향 × F.A 방향으로 계산 (예전엔 F.A 를 늘 선수로 보고 계산해 F.A 선미 블록에서 회전오차가 10° 넘게 틀어짐)
- **한 방향씩 저장** : 지주캡 B · A, 현물 기준 T.A · F.A 를 단계마다 저장 — 뒤로 가거나 화면을 나가도 남음
- 높은 쪽을 반대로 고른 것 같으면 결과 화면에 경고 + 한 번 눌러 고치기
- 현물 기준 F.A 가 도면 방향과 반대면 경고
- 측정 방향 그림 교체 (TS · PSA 주판 기준, T/A · F/A), 측정 안내를 그림의 부재 번호로
- CSV 끝에 F.A방향 · 실측B높은쪽 · 정상B높은쪽 열 추가 (앞 열 순서는 그대로)
- CSV 내보내기에 **다운로드 폴더에 저장** 추가 (다른 앱으로 보내기와 골라 씀)
