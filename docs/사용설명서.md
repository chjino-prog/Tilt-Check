# TILT CHECK 사용설명서

## 화면 구성
| 탭 | 하는 일 |
|---|---|
| 측정 | 블록 목록(호선별) → 블록 → 지주캡 측정 / 다른 부재 재기 |
| 기록 | 블록별 측정 기록, CSV 내보내기 |
| 설정 | 판정 기준, 영점 보정, 표시 자릿수, 진동, 테마 |

## 먼저 알아둘 것
- 폰 중력센서는 기기 · 케이스에 따라 0.1 ~ 0.5° 오차가 납니다. **판정은 디지털 수평계를 우선으로** 하고, 폰 값은 참고로만 씁니다.
- 앱을 켜고 처음 측정 화면에 들어갈 때마다 이 경고가 한 번 뜨고, 측정 · 결과 화면 아래에도 표시됩니다.
- 디지털 수평계 값은 '직접 입력'으로 넣으면 같은 계산(역산 · 잔차 · 판정)을 합니다.

## 폰 대는 법
앱은 두 가지를 잽니다.

| 재는 것 | 폰 대는 법 | 쓰는 곳 |
|---|---|---|
| **선 재기** (폰 긴 축의 기울기) | 폰을 **세워서 긴 옆면**을 잴 선에 댐 | 지주캡 A · B, T.A, LONGL. 라인, 다른 부재 |
| **판 기울기 재기** (화면이 하늘을 향한 각) | 폰 **뒷면**을 판에 붙임 | 현물 기준 F.A — FRAME 웹 |

- 선 재기는 **폰 긴 축이 어느 선을 따라가느냐**만 봅니다. 긴 옆면 전체가 주판에 닿으면 옆으로 조금 기울어도 같은 값입니다.
- **세워서 재는 것을 권합니다.** 눕히면 뒷면 카메라 돌출부 때문에 머리 쪽이 들려 0.5 ~ 1° 틀어질 수 있습니다 (케이스로 뒷면이 평평하면 눕혀도 됨). 영점 보정도 세워서 합니다.
- 폰 긴 축을 위아래로 세워 WEB · FRAME 웹 면에 대면 안 됩니다 — 판 위 선 하나라 대는 방향마다 값이 달라집니다.
- 숫자 옆 ▲ = 폰 **윗단(카메라 쪽)이 높음**, ▼ = 윗단이 낮음.
- 케이스 · 카메라 돌출부 때문에 옆면이 뜨지 않게 대세요. 뜨면 케이스를 벗기고 영점 보정을 다시 합니다.
- 테두리가 **초록**이 되면(안정) 화면 아무 곳이나 눌러 값을 고정합니다. 다시 누르면 풀립니다.
- '움직임 감지' 가 뜨면 값 갱신을 멈춘 상태입니다. 폰을 멈추면 다시 잽니다.

## 부호(+/−)는 쓰지 않습니다 — 방향만 고릅니다
도면이 "F.A 선미로 3.2°", "캡 선미로 7°" 처럼 주는 그대로, 앱에도 **숫자 + 선수/선미** 로 넣습니다. 부호는 앱이 붙입니다.

| 넣는 곳 | 넣는 것 |
|---|---|
| 블록 | T.A 숫자, **F.A 숫자 + F.A 방향(선수/선미)**, 잴 때 지주캡이 보는 쪽(바닥 / 하늘) |
| 지주캡 | δ 숫자 + 돌아간 방향(선수/선미) + **캡 자리 외판 기울기** (δ 0 캡은 빼고) |
| 각도 B (F/A 방향) | 숫자 + **높은 쪽(선수/선미)** (폰이면 폰 머리를 선수 쪽으로 대고 확인 버튼) |
| 각도 A (T/A 방향) | 숫자만 (어느 쪽으로 대도 됨) |

- 숫자 칸에 '-' 를 쳐도 지워집니다. 디지털 수평계 ▲▼ 는 **높은 쪽 고르기**로만 옮깁니다.
- **F.A 방향 = FRAME 이 누운 쪽** 입니다. 도면 'F.A 선미로 3.2°' = FRAME 이 선미 쪽으로 3.2° 누움. 앱은 블록 · 현물 · 보고서에 '선미로 누움'처럼 보여 줍니다.
- FRAME 과 LONGL. 은 직각이라 **누운 쪽 = LONGL. 라인의 낮은 끝**입니다. F.A 선미 블록이면 TS캡(δ=0) · DECK LONGL. 라인은 **선수 쪽이 높습니다** (2026-11-21 현장 확인).
- 곡블록은 블록 끝의 높낮이가 외판 모양에 묻혀 눈으로 가리기 어렵지만, FRAME 이 누운 쪽은 블록 자세(외판 BASE · 내벽 BASE · 뒤집힘)와 상관없이 그대로 맞습니다.
- 계산 : F.A 와 캡이 같은 쪽(선미·선미, 선수·선수)이면 같은 식, 반대면 반대 식으로 계산합니다. F.A 선미 블록은 선수·선미를 통째로 뒤집어 본 F.A 선수 블록과 같기 때문입니다.
- 1.2.0 전에 만든 블록은 F.A 방향이 비어 있어 **선수로 계산**합니다. 캡 화면에 'F.A 방향을 아직 안 정했어요' 가 뜨면 눌러서 정합니다.

## 지주캡 측정
1. 블록 추가 : 호선, 블록, **T.A TRANSVERSE ANGLE**, **F.A FRAME ANGLE + FRAME 이 누운 쪽(선수/선미)** (T.A · F.A 는 선택 — 모르면 비워 두고 아래 '현물 기준'으로 잽니다), **잴 때 지주캡이 보는 쪽** (보통 바닥, 턴오버 후 확인이면 하늘 — 아래 '외판 기울기 · 턴오버')
2. 지주캡 추가 : 캡 No, **δ**(도면 캡 취부각도 그대로), 돌아간 방향(선수 / 선미), **캡 자리 외판 기울기** (δ 가 있는 캡만 — '어디를 재나요?' 그림)
3. 캡을 누르면 **측정 순서 화면**이 나옵니다 — 정상값 카드(B · A, dA, dB)와 B · A 두 줄.
   - 정상 B 는 '0.74° · 선미 높음' 처럼 높은 쪽으로 보여 줍니다.
   - 카드 위에 어느 기준(도면 / 현물)의 T.A · F.A 로 계산했는지 표시됩니다.
   - δ 가 0 인 캡은 돌아간 방향(선수/선미)을 표시하지 않습니다.
   - dA 가 'A 민감도 하한'(기본 0.3)보다 작으면 A 는 회전 판정에 못 쓰고 참고로만 봅니다.
4. **측정** (측정 방향 그림 : 메뉴 › 측정 방향 그림 — 폰용 입체 그림과 디지털 수평계용 그림)
   - 기준은 **FRAME 선이 아니라 캡 자신의 WEB · 브라켓**입니다. δ 가 있는 캡도 재는 법은 같고 정상값만 다릅니다. FRAME 선 · LONGL. 선을 따라 재면 도면대로 붙은 캡도 회전오차가 δ 만큼 나옵니다.
   - **B (WEB 직각)** : 주판 위, 브라켓과 평행 (TS = ④ 주판 · ②③ 과 평행, PSA = ③ 주판 · ④⑤ 와 평행). 폰을 세워 뒷면을 브라켓에 기대면 방향이 저절로 맞습니다.
     - 폰 : **폰 머리(카메라 쪽)를 선수 쪽으로** 대고 **'네, 선수 쪽으로 댔어요'** 를 눌러야 값을 고정할 수 있습니다 (잴 때마다). 그러면 '▼ 선미 쪽이 높아요' 처럼 크게 알려 줍니다. 반대로 댔으면 '선미 쪽으로 댔어요' 를 누릅니다.
     - 디지털 수평계(직접 입력) : 숫자를 넣고 **어느 쪽이 높아요? ▲ 선수 / ▼ 선미** 를 고릅니다. 안 고르면 다음으로 못 갑니다.
     - 두 경우 모두 '이렇게 저장돼요 : 선미 쪽이 1.60° 높음' 이 보이니 한 번 더 확인합니다.
     - PSA 캡처럼 정상 B 가 허용오차보다 작은(거의 수평) 캡은 '높은 쪽을 반대로 골라도 B 편차가 작게 나오는 캡' 주황 경고가 뜹니다.
   - **A (WEB 방향)** : 주판 위, WEB 과 평행 (TS = ① 과 평행, PSA = ①② 와 평행). 숫자만, 방향 상관없음. 폰을 세워 뒷면을 WEB 에 기대면 방향이 저절로 맞습니다.
   - **한 방향씩 저장** : '저장하고 A 재기' 를 누르면 B 값이 바로 저장됩니다. 뒤로 가거나 화면을 나갔다 와도 남아 있고, 순서 화면에서 그 줄만 눌러 다시 잴 수 있습니다. 하루 지난 값은 버립니다. 메뉴 › '잰 값 지우고 처음부터'로 지웁니다.
5. 결과
   - **판정 (1.7.0)** : 각도 A · B 의 **현물 · 정상 · 편차**를 크게 보여 주고, 편차가 **합격 허용오차(기본 ±3.0°)** 안이면 OK, 하나라도 넘으면 NG.
   - **주의** : A · B 는 안인데 역산 회전오차가 허용오차를 넘거나 역산이 안 되면 노란 '주의'. T.A 24° 미만 블록이면 'B 오차가 회전각에 약 N배로 커진다' 는 설명이 함께 뜹니다.
   - **참고값** (작게, 회색) : 역산 회전오차 = 실제 δ − 도면 δ (B 값으로 역산), 실제 δ (도면과 같은 **외판 위 각도**), A 잔차, 회전 환산 배율(B 1° → 회전 N°). 옆 **(?)** 에 판정에 안 쓰는 이유가 있습니다.
   - **A 잔차** 가 기준(기본 0.5°)을 넘으면 참고값에 'WEB 숙어짐 · 측정 위치 의심' 이 주황으로 뜹니다
   - 평면도 : 빨간 점선 FRAME선, 회색 도면 WEB, 파란 실제 WEB
   - 역산 회전오차는 '선미 쪽으로 4.00° 덜 돌아감' 처럼 글로도 보여 줍니다. δ 0 캡은 '선수 쪽으로 0.65° 돌아감'.
   - **방향 점검** : A 는 캡이 돌아도 거의 안 바뀌고 방향에만 크게 바뀝니다. 실측 A 가 반대 방향 정상 A 에 훨씬 가까우면 빨간 화면으로 **판정을 보류**하고 **FRAME 누운 쪽 · 캡 방향 · 잴 때 지주캡이 보는 쪽(턴오버)** 셋 중 틀린 것을 고치게 합니다 (F.A 3° 이상, δ 가 있는 캡). 고치면 같은 잰 값으로 바로 다시 계산합니다.
   - **높은 쪽이 판정을 가르는 캡**은 '기록대로 / 반대였다면' 두 결과를 나란히 보여 주고, **B 다시 재기**로만 고칩니다 (한 번 눌러 뒤집는 버튼은 없앴습니다).
   - A · B 를 바꿔 넣은 것 같으면 경고가 뜹니다.
6. 메모 · 사진(선택)을 붙여 **기록 저장** (저장하면 잰 값은 지워짐)

## 외판 기울기 · 턴오버 · 도면 T.A (1.6.0)
δ 가 있는 캡(PSA · PSB)이 '도면보다 더 돌아감' · '방향이 반대 같음' 으로 나오던 원인 두 가지와, 도면 T.A 가 현물보다 크게 나오던 원인을 고쳤습니다. 계산식은 작업지시서 그대로이고, **식에 들어가는 값**만 바르게 바꿉니다. 자세한 식은 `docs/계산식.md`.

### 캡 자리 외판 기울기
- 도면 캡취부각도는 **외판을 정면에서 본 그림**이라, δ 는 외판 위에 그은 FR 선과 캡 중심선 사이 각도입니다.
- 폰은 캡 **상판**에서 잽니다. 캡 WEB 은 세로판이라, 외판이 서 있을수록 외판 위에서는 덜 돌아간 것처럼 보입니다 (문을 열어도 벽에 붙은 경첩 선은 늘 세로인 것과 같음).
- 그래서 외판 기울기로 도면 δ 를 상판 각도로 바꿔 계산합니다. 작은 δ 는 대략 **δ ÷ cos(외판 기울기)** : 외판 45° 면 약 1.4배, 60° 면 2배, 75° 면 약 3.9배.
- **재는 곳** : 캡이 있는 FR 단면도에서, 캡이 붙은 점의 **외판 접선과 A/B 수평선 사이 각** (0 ~ 90°, 누운 외판 0°, 선 외판 90°). 보는 방향(선미→선수 / 선수→선미)은 상관없고, 1° 단위면 충분합니다. 캡 추가 시트의 '어디를 재나요?' 그림 참고.
- 결과의 실제 δ · 회전오차는 다시 **외판 위 각도**로 돌려 도면 δ 와 바로 비교합니다. 그래서 외판 기울기를 1 ~ 2° 틀리게 읽어도 회전오차는 0.2 ~ 0.4° 정도만 움직입니다.
- **θ 를 아직 모르면 비워 두고 먼저 재도 됩니다** (1.7.1). 설계 반영 전이라 현물에서 θ 를 먼저 재는 경우입니다.
  - 결과는 'θ 를 넣으면 판정해요' 로 나오고, 잰 값(A · B · 높은 쪽)만 'θ 미입력' 기록으로 저장됩니다.
  - 사무실에서 블록 › 캡 › ··· › 지주캡 수정에서 θ 를 넣거나, 기록 상세의 '캡 θ 넣기' 를 누르면 **그 캡의 기록이 잰 값 그대로 저절로 다시 계산**됩니다. θ 를 고쳐 넣어도 같습니다.
  - 블록 화면에 'θ 를 기다리는 기록이 있는 캡 N개' 가 뜨고, 보고서 · CSV 에는 판정 대신 'θ 미입력' 으로 남습니다.
  - 누운 외판(보정 없음)은 **0** 을 넣습니다.
- 1.7.0 부터 정확식(tan δ외판 = tan δ상판 × cos 외판 기울기)으로 계산해, δ 가 커도 막히지 않습니다. 외판 기울기는 90° 보다 작게 넣습니다.

### 턴오버 후 확인 (잴 때 지주캡이 하늘을 봄)
- 도면의 '돌아간 방향' 은 캡 WEB 의 **외판 쪽(바깥) 끝**이 가는 쪽입니다.
- 보통처럼 **캡이 바닥을 볼 때** 그 끝은 **아래 끝**, 블록을 **턴오버해 캡이 하늘을 볼 때**는 **위 끝**이 됩니다. 선수 · 선미는 그대로지만, 폰 값(A · B)은 위 끝이 어디로 갔는지로 정해져서 계산이 반대가 됩니다.
- 턴오버한 블록을 재면 블록 수정에서 **잴 때 지주캡이 보는 쪽 = 하늘** 로 바꿉니다. 깜빡해도 방향 점검이 잡아 보류 화면에서 바로 바꿀 수 있습니다.
- T.A · F.A 는 **잴 때 자세의 값**이어야 합니다 (현물 기준이면 그 자세에서 잰 값).

### 도면 T.A → 실제 경사
- 도면 T.A 는 단면도(FRAME 면)에서 본 각입니다. 그 FRAME 면이 F.A 만큼 누우면 같은 선이 덜 가팔라집니다 : **sin(경사) = sin T.A × cos F.A**. 예) 도면 T.A 45° · F.A 10° → 경사 44.13°.
- 도면 기준으로 계산할 때만 바꿉니다. 블록 카드 · 캡 화면에 '경사' 로 같이 보여 주고, 현물 T.A 와도 경사로 비교합니다. 현물 T.A 는 폰이 경사를 바로 재므로 그대로입니다.
- F.A 가 3° 면 차이가 0.06° 라 거의 같고, F.A 가 8 ~ 13° 인 블록에서 0.7 ~ 1.6° 차이 납니다.

### 지난 기록 다시 계산
- 기록 상세에 '새 계산으로 다시 계산할 수 있어요' 가 뜨면 **다시 계산해서 저장** 을 누릅니다. 잰 값(A · B · 높은 쪽)은 그대로 두고, 지금 캡의 외판 기울기 · 블록의 턴오버 · 도면 T.A 경사로 정상값 · 회전오차 · 판정을 다시 매깁니다.
- 1.6.0 전에 저장한 기록은 '계산 방식 : 1.6.0 전' 으로 표시됩니다. CSV 끝에 외판기울기 · δ상판 · 실제δ상판 · 캡자세 · 도면T.A · 계산방식 칸이 붙습니다 (예전 칸 위치는 그대로).

## 현물 기준 (T.A · F.A 를 몰라도 될 때)
도면 T.A · F.A 대신, 지금 작업 중인 블록의 기준 부재를 **같은 폰으로** 재서 그 값으로 정상값을 계산합니다. 계산식은 그대로이고 들어가는 T.A · F.A 만 바뀝니다.

T.A · F.A 는 '블록이 어떻게 놓였나'가 아니라 **배의 FRAME 수평선 · FRAME 면이 지금 얼마나 기울었나**입니다. 외판 BASE 든 내벽(HOPPER · L.BHD) BASE 든 뜻은 같고, 잴 수 있는 곳만 다릅니다.

| 부재 | 쓰임 |
|---|---|
| BASE 로 깐 판 위 (외판 · HOPPER · L.BHD) | ✕ 일부러 평평하게 깔아서 어디를 재도 0° 근처 |
| 배 안에서 기운 판(HOPPER 등)의 FRAME 방향 선 | ✕ 판 경사가 섞여 T.A 가 아님 |
| FRAME 웹에 폰 긴 옆면 | ✕ 웹 위 선 하나 — 대는 방향마다 0° ~ (90° − F.A) |
| FRAME 웹에 폰 뒷면 | **F.A** (판 기울기 재기) |
| CENTER LINE 과 평행한 GIRDER · 론지 | **F.A** (선 재기, 디지털 수평계도 가능) |
| DECK · FLAT · STRINGER 상면 FRAME 선, 웹 수평 보강재 | **T.A** |

1. 블록 화면 → **현물에서 재기**
2. 1/2 **T.A** : 배 기준 수평인 FRAME 방향 선에 폰을 세워 긴 옆면을 댑니다. 숫자만.
3. 2/2 **F.A · FRAME 웹** (기본)
   - **선수를 보고 서서** 눈앞 FRAME 웹에 폰 **뒷면**을 붙입니다. 잴 때마다 '네, 선수를 보고 있어요'를 누릅니다 (반대로 섰으면 '선미를 보고 있어요').
   - **폰 머리를 위로** 해서 고정 → **거꾸로 돌려** 같은 자리에서 한 번 더 고정 → 두 값의 평균이 F.A 입니다. 케이스 · 카메라 돌출부로 들뜬 만큼이 서로 지워집니다. 두 값이 0.5° 넘게 다르면 '뒷면이 들떠요' 경고가 뜹니다.
   - 폰을 웹 위에서 어떻게 돌려 붙여도 같은 값입니다. 보강재 · 용접 · 구멍은 피합니다.
   - 화면이 하늘을 보면 FRAME 이 바라보는 쪽으로, 땅을 보면 내 쪽으로 누운 것입니다. 앱이 'FRAME 이 선미 쪽으로 5.20° 누웠어요 → F.A 선미 5.20°'로 바꿔 보여 줍니다.
   - 처음 한 번 **뒷면 보정**이 필요합니다 (설정 › 뒷면 보정).
   - **다른 방법 · LONGL. 라인** : 'LONGL. 라인으로 재기'를 누르면 예전 방식(긴 옆면 + 폰 머리 → 선수)으로 잽니다. DECK · GIRDER 가 있는 블록이나 디지털 수평계로 잴 때 씁니다. 높은 쪽의 반대가 FRAME 이 누운 쪽입니다.
4. 확인 화면 : 옆에서 본 FRAME 그림과 'FRAME 이 선미로 5.20° 누움 → F.A 선미 5.20°'. 저장 버튼도 '선미로 누웠어요 · 저장'이라 눈으로 확인하고 저장합니다.
   - 도면 F.A 방향과 반대로 나오면 'FRAME 누운 쪽이 도면과 반대예요' 빨간 경고, 도면값이 없으면 눈으로 한 번 더 보라는 주황 경고
   - 둘 다 일반 편차 1단계(기본 0.5°) 안이면 '블록 세팅이 도면과 거의 같아요', 2단계를 넘으면 잰 곳을 확인하라는 경고
   - F.A 가 T.A 보다 크면 T.A 를 배 기준 수평선에서 쟀는지 확인하라는 경고
5. 저장하면 그 블록의 지주캡 · 다른 부재가 모두 현물값으로 계산됩니다.

- T.A · F.A 숫자는 크기만 씁니다. 두 값은 하나씩 저장되며, 한쪽만 재고 나가도 남습니다.
- 도면값 · 현물값이 둘 다 있으면 블록 화면에서 **계산 기준(도면값 / 현물값)** 을 바꿀 수 있습니다.
- 블록을 복제하면 현물값은 복사되지 않습니다 (블록마다 다시 잽니다).
- 측정 화면의 '어디에 대요?' 를 누르면 기준 부재 고르는 법이 나옵니다.

## 다른 부재 재기 (추가 기능)
블록 화면 → '다른 부재 각도 재기'
- **FRAME** (정상값 = T.A) / **LONGL.** (정상값 = F.A) — 현물 기준이면 '(현물)' 표시 / **임의각** (ψ, 선수/선미 입력, 블록 F.A 방향 반영)

- 허용 1단계 이하 초록, 2단계 이하 주황, 넘으면 빨강.
- 기울기 그림의 차이는 눈에 보이도록 5배로 그립니다 (숫자는 실제 값).

## 영점 보정
1. 평평한 곳에 폰 긴 옆면을 대고 첫 번째 값 저장
2. 폰을 **들어서** 180° 돌려 같은 자리에 대고 두 번째 값 저장 (폰을 움직이지 않으면 저장 안 됨)
3. **카메라 쪽을 살짝(3° 넘게) 들어** ▲ 로 읽는지 확인 — ▼ 로 읽는 기기면 앱이 방향을 바로잡아 저장합니다
- 영점 보정을 안 한 폰은 기준 부재와 지주캡을 **같은 쪽(선수)으로 대야** 폰 치우침이 지워집니다 (반대로 대면 0.3° 치우침이 회전오차 1° 가까이로 커짐).

### 뒷면 보정 (판 기울기 재기용)
영점 보정은 폰 긴 축만 바로잡습니다. FRAME 웹에 폰 뒷면을 붙여 재는 '판 기울기'는 화면 축을 쓰므로 따로 한 번 보정합니다.
1. 케이스를 끼운 그대로 책상에 **화면이 위로** 놓고 저장
2. 같은 자리에 **엎어서(화면이 아래로)** 놓고 저장 → 두 값의 가운데가 보정값. 화면 방향을 반대로 읽는 기기는 앱이 바로잡습니다.

### 1.7.0 (2026-11-25)
- **판정 체계 변경** : 합격 · 불합격 = 각도 A · B 실측과 정상값의 단순 비교. 역산 회전각은 참고값으로 작게 보여 줌
- **판정 3단계** : NG(A 또는 B 편차 > 허용오차) / 주의(A · B 는 안, 역산 회전이 허용오차를 넘거나 역산 불가) / OK
- **합격 허용오차** 설정 추가 (기본 ±3.0°, 0.1° 단위). 결과 화면 위 '합격 허용오차' 를 눌러도 바꿀 수 있고, 바꾸면 바로 다시 판정. 기록에 그때 허용오차를 남김
- **회전 환산 배율(1/sin T.A)** 을 참고값에 표시. T.A 24° 미만 블록에서 주의가 나오면 '역산 회전각이 약 N배로 커진다' 는 설명을 함께
- 참고값 옆 **(?)** : 역산 회전각을 판정에 쓰지 않는 이유 (오차 증폭 · 2026-11-25 현장 사례)
- **외판 기울기 보정 정확식** : tan δ외판 = tan δ상판 × cos θ. 'δ ≥ 90° − θ 입력 불가' 삭제, 1°당 변화(k)도 정확식으로
- 높은 쪽 점검('높은 쪽이 판정을 가름' · '반대로 고르지 않았나요?')도 B 편차 기준으로
- CSV 끝에 판정기준(A·B) · 역산회전(참고) · 회전 환산 배율 · 경고(주의 사유) · 허용오차 칸, 계산방식 '1.7.0'
- 지난 기록은 기록 상세의 '다시 계산해서 저장' 으로 1.7.0 판정을 매길 수 있음 (잰 값은 그대로)

### 1.6.0 (2026-11-24)
- **캡 자리 외판 기울기** : 도면 δ(외판 위 각도)를 캡 상판 각도로 바꿔 계산. 서 있는 외판의 δ 캡이 '도면보다 더 돌아감' 으로 나오던 문제 (외판 40 ~ 75° 캡 6개에서 회전오차 2.7 ~ 15° → 2° 안)
- **턴오버 후 확인** : 블록에 '잴 때 지주캡이 보는 쪽(바닥 / 하늘)'. 하늘이면 캡 방향 계산을 뒤집음. 방향 보류 화면에서도 바로 고침
- **도면 T.A → 실제 경사** : sin(경사) = sin T.A × cos F.A. 도면 기준 계산 · 현물 비교 · 보고서에 반영
